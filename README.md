# ✊🏿 Consciência Negra

Projeto educativo desenvolvido para apresentar informações sobre a história, cultura, resistência e importância da Consciência Negra.

## 📚 Sobre o projeto

O projeto aborda temas relacionados à história da população negra no Brasil, cultura afro-brasileira, personalidades importantes e combate ao racismo.

O site possui:

- 🏠 Página inicial
- 📖 História da população negra
- 🎭 Cultura afro-brasileira
- ✊🏿 Personalidades importantes
- 🧠 Quiz interativo
- 💭 Seção de reflexão
- 📱 Design responsivo
- 📱 Menu para dispositivos móveis

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash
